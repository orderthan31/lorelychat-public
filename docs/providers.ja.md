# プロバイダー設定

[한국어](providers.ko.md) | [English](providers.md) | [日本語](providers.ja.md)

## Mock モード

`LLM_MOCK=true` はインストールを検証するためのモードです。プロバイダーアカウントは不要で、有料の生成リクエストも送信しません。

## Web UI でプロバイダーアカウントを設定する

通常は次の手順で設定します。

1. Mock モードで起動します。
2. **設定 → モデル管理**を開きます。
3. 正しいプロトコルとベース URL でプロバイダーアカウントを作成します。
4. API キーを保存します。
5. 対応するチャットモデルを同期するか、手動で追加します。
6. ランタイムの既定モデルを指定します。
7. Mock モードを無効にし、API コンテナを再作成します。

プロバイダーキーは `/secrets/provider_secrets.json` に平文の JSON 値として保存され、データベースレコードからは内容を示さない ID で参照されます。POSIX 権限に対応するファイルシステムでは、ファイルモード `0600` で作成されます。Lorechat は API レスポンス内のキーをマスクしますが、シークレットファイル自体は暗号化しません。

## ローカル OpenAI-compatible エンドポイント

Docker 内の `127.0.0.1` は API コンテナ自身を指します。Docker ホストで動くモデルサーバーに接続するには、次の値を使用してください。

```dotenv
LLM_BASE_URL=http://host.docker.internal:11434/v1
```

Compose ファイルは Linux で `host.docker.internal` をホストゲートウェイに割り当てます。モデルサーバーが Docker から到達できるアドレスで待ち受けていること、信頼できないネットワークから保護されていることを確認してください。

## プライバシー

実際のプロバイダーには、生成に必要な構築済みプロンプトと会話コンテキストが送信されます。送信する権限のないデータを含むルームには、第三者プロバイダーを設定しないでください。

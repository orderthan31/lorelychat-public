# Contributing

Thanks for helping improve Lorechat.

## Current contribution policy

Bug reports, documentation feedback, and security reports are welcome. Code pull requests are temporarily not accepted.

The project uses a noncommercial source-available license and may later offer separately negotiated commercial permissions. Accepting third-party code before a contributor or relicensing agreement exists could create unclear rights for contributors and maintainers. A future contributor policy will define those terms before code contributions are accepted.

## Bug reports

Please include:

- exact version or commit
- operating system and Docker versions
- reproduction steps
- expected and actual behavior
- sanitized logs

Never attach `.env`, API keys, provider-secret files, runtime databases, private character cards, conversation exports, or uploads.

## Security reports

Follow [SECURITY.md](SECURITY.md). Do not report exploitable vulnerabilities in a public issue.

# プロバイダー設定

[한국어](providers.ko.md) | [English](providers.md) | [日本語](providers.ja.md)

## Mock mode

`LLM_MOCK=true` はインストール状態を確認するためのモードです。プロバイダーのアカウントは不要で、有料の生成リクエストも送信しません。

## Web UI でプロバイダーアカウントを設定する

通常は次の手順で設定します。

1. Mock mode で起動します。
2. **設定 → モデル設定**を開きます。
3. 正しいプロトコルと base URL でプロバイダーアカウントを作成します。
4. API key を保存します。
5. 対応するチャットモデルを同期するか、手動で追加します。
6. ランタイムの既定モデルを指定します。
7. Mock mode を無効にし、API コンテナを再作成します。

プロバイダー key の値は `/secrets/provider_secrets.json` に平文の JSON として保存され、データベースのレコードから不透明な ID で参照されます。POSIX 権限に対応するファイルシステムでは file mode `0600` で作成されます。Lorechat は API 応答内の key をマスクしますが、機密情報ファイル自体は暗号化しません。

## Local OpenAI-compatible endpoint

Docker 内の `127.0.0.1` は API コンテナ自身を指します。Docker ホストで動くモデルサーバーに接続するには、次の値を使用してください。

```dotenv
LLM_BASE_URL=http://host.docker.internal:11434/v1
```

Compose ファイルは Linux で `host.docker.internal` をホストゲートウェイに割り当てます。モデルサーバーが Docker から到達できるアドレスで待ち受けていること、信頼できないネットワークから保護されていることを確認してください。

## プライバシー

実際のプロバイダーは、生成に必要なコンパイル済みプロンプトと会話コンテキストを受け取ります。送信する権限のないデータを含むチャットルームには、外部プロバイダーを設定しないでください。
